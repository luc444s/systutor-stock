# Stock Plugin

Plugin de stock para SYSTUTOR OSS.

Implementa:

- ledger inmutable de movimientos;
- balance sincronizado por producto y almacen;
- configuracion de minimo/maximo;
- ajustes manuales;
- transferencias entre almacenes;
- auditoria y eventos.

Dependencias:

- `productos` para `prod_products`.
